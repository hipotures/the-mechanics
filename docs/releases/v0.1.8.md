Outline buttons get the control face; Firefox date/time fields show one icon.

## Changed
- **Outline buttons (`.tm-btn--outline`) now have the control face** (`--tm-inset`), the same as fields, selects and segmented controls. Before, they were transparent, so an outline button beside selects showed the page background. Hover and press tints are layered over the face. Ghost buttons stay transparent. CSS only.
  - If your app made outline buttons opaque by itself, you can remove that override.

## Fixed
- **Firefox showed two icons in date and time fields**: its own calendar/clock button plus ours. Firefox gives no way to hide its button. In a `.tm-picker-field`, our button now covers it, so the native icon can no longer be clicked. Firefox only, CSS only.

## Notes for apps
- **A bare `<input type="date">` or `<input type="time">` opens the browser's own calendar or clock, whatever the CSS.** In Firefox that popup is rounded, starts on Sunday and has red weekends. Every date/time field must be wrapped by the picker script (`enhanceDateTime` → `.tm-picker-field`). Check this in menus and dialogs too.
  - The rendered audit (`skills/the-mechanics/scripts/ui-audit.mjs`) reports `system-popup` for any date or time field that is not wrapped.
- The field's own 12/24 h display follows the browser language, not the page `lang`. The picker popup is always 24 h.

## Testing
