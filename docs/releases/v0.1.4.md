Select fallback: long option lists scroll again.

## Fixed
- **The scripted select list closed as soon as it was scrolled.** This is the fallback for browsers without `appearance: base-select`, e.g. Firefox. The mouse wheel, dragging the scrollbar and clicking the scrollbar all closed it. The light-dismiss `scroll` listener on `window` (capture phase) also caught the list's own scroll events. Now only a page scroll or a click outside closes the list, and the listeners are removed when it closes.
- **Menu and option items no longer select their text** when you drag across them (`.tm-menu__item { user-select: none }`, in the CSS).

## Apply in your app (the installer does not update this code)
`enhanceSelects` is reference JavaScript that apps copy, often as `tm-select.js`. Find this line in your copy:

    window.addEventListener("scroll", () => close(false), { once: true, capture: true, passive: true });

Replace the light-dismiss block so that a scroll inside the list is ignored and both listeners are removed in `close()`:

    // in the per-select scope, before close():
    let dismiss = null;
    // first lines of close(), after `if (!list) return;`:
    dismiss?.(); dismiss = null;
    // light dismiss, after the list is shown:
    setTimeout(() => {
      if (!list) return;
      const away = (e) => { if (list && !list.contains(e.target) && e.target !== sel) close(false); };
      const scrolled = (e) => { if (list && !list.contains(e.target)) close(false); };
      document.addEventListener("pointerdown", away, true);
      window.addEventListener("scroll", scrolled, { capture: true, passive: true });
      dismiss = () => {
        document.removeEventListener("pointerdown", away, true);
        window.removeEventListener("scroll", scrolled, { capture: true });
      };
    });

The full reference is `src/playground/lib.js` → `enhanceSelects` at this tag. Any other scripted popup with a scrollable list and a capturing scroll listener needs the same `list.contains(e.target)` check.
