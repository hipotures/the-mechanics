First release of **The Mechanics** — a standalone, CSS-only design system (Sharp Retro-Tech / Structured Technical Minimalism) with a multi-application visual playground.

## Assets
- **`the-mechanics-css-v0.1.0.zip`** — compiled, framework-free distribution: `the-mechanics.css`, `fonts.css` + self-hosted IBM Plex Sans/Mono (OFL, licenses included), `the-mechanics.daisyui.css` (optional Tailwind 4 + daisyUI 5 bridge), `distribution.md` with import instructions for plain HTML, React, Svelte and Rust/Datastar.
- **`the-mechanics-skill-v0.1.0.zip`** — Claude Code agent skill for applying the system in another project: owner-approved rules not visible in the CSS, copy-ready recipes and source/rendered-page audit scripts. Unzip into `<project>/.claude/skills/` (or `~/.claude/skills/`).
- `SHA256SUMS`

## What is included
- Public namespaced API: `--tm-*` tokens, `.tm-*` classes, `data-tm-theme` on `<html>`.
- Three themes with identical geometry: **Light / Paper-Stone**, **Dark / Graphite**, **Coffee / Espresso-Mocha**.
- Three-level visual hierarchy (regions → panels/tables → nested groups), ink focus "lift", status plates, condition toasts, single tooltip look.
- Playground: Analytics, Workspace, Data Management, Commerce, Website/Content apps and the Component Gallery (`#/components`), driven by `fixtures/demo-data.json`.
- Component status per group: `docs/component-status.md`.
