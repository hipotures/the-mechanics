Accessibility and performance pass: selected rows in Dark and Coffee now meet WCAG AA, and the demo loads two to three times faster.

## Changed
- **Selection and danger tokens in Dark and Coffee.** Muted text, counts, negative amounts and status colors on a selected row were at 3.2–3.6:1. They now reach 4.5:1:
  - Dark: `--tm-select-bg` `#4a5c3a` → `#3b492e`, `--tm-danger` `#f29180` → `#f39b8c`;
  - Coffee: `--tm-select-bg` `#74492a` → `#5f3c23`, `--tm-danger` `#f3977f` → `#f39b84`.

  The selection is still a fill without a frame, only darker. Light is unchanged.
- **Base layer (`.tm-root`):**
  - headings break into balanced lines (`text-wrap: balance`); paragraphs and list items avoid a lone last word (`pretty`);
  - no grey tap flash; controls have `touch-action: manipulation`;
  - when the page has a `.tm-topbar`, `<html>` gets `scroll-padding-top`, so focused elements and in-page link targets land below the sticky bar (WCAG 2.4.11).
- **Scrolling panels** (sidebar, listbox, picker columns, command palette list, drawer and sheet bodies) no longer scroll the page behind them when they reach the end (`overscroll-behavior: contain`).
- **daisyUI bridge:** inactive `.d-tab` labels use `--tm-text-2`. daisyUI's 50% mix was about 3:1.
- **Sheet recipe:** use `<div class="tm-sheet" popover="manual" role="dialog" aria-labelledby="…">`. An `<aside>` cannot have `role="dialog"`.

## Apply in your app
1. Re-run the installer (below). Nothing to change if you only use tokens and `tm-*` classes.
2. If you hard-coded the old Dark/Coffee selection or danger hex values anywhere, switch to the tokens.
3. Sheets built on `<aside role="dialog">`: change the element to `<div>`. The classes stay the same.
4. Text rendered on `--tm-select-bg` (for example a custom selected cell) should use `--tm-text`, `--tm-text-2`, `--tm-text-3` or the status tokens. All of them now pass 4.5:1 there in every theme.
