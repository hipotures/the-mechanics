## Changed
- **New `.tm-caret`.** A button that opens a menu ("More", "Actions") now ends with the same solid triangle, in the same color, as the select's caret. Before, the gallery showed a stroked chevron icon on menu buttons, so a "More" button beside selects showed two different down-arrows. Use `<span class="tm-caret" aria-hidden="true"></span>` in place of a chevron icon on menu buttons. Stroked chevrons stay for navigation (back / next) and in-place expansion (nav groups, collapsible sections).
- The rule is in DESIGN.md (Menu / popover), the skill (rule 11, `references/rules.md` Fields) and `references/recipes.md` (Buttons).
