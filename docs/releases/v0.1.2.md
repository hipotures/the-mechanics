Fix release for the distributed fonts.

## Fixed
- **`fonts.css` had `unicode-range:undefined` in every `@font-face`** (v0.1.0 and v0.1.1). Browsers ignore the invalid descriptor, so fonts loaded, but the latin / latin-ext split did not work. Each face now has its real range, and the build fails if a range is missing. In Chromium, a page with ASCII text loads only the latin file; Polish text adds latin-ext.

The CSS components, tokens and skill rules are unchanged from v0.1.1. The playground was never affected because it imports @fontsource directly.

## Upgrade
Re-run the installer from the project root. It replaces only the directories it created:

    curl -fsSL https://github.com/hipotures/the-mechanics/releases/latest/download/install.sh | sh
