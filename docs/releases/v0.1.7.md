## Changed
- **Product card:** the lines inside one card are now **1px ink**: image | body, body | footer, price | action. The card frame and the lines between cards stay 2px. This uses the same test as v0.1.6 (several things, or parts of one thing?). The change is in `the-mechanics.css`.

## Fixed
- **The date picker stayed on screen while the page scrolled away under it.** All anchored popups now follow one rule:
  - select list, menu, date/time picker and multi-select follow their field while the page scrolls;
  - scrolling inside the popup changes nothing;
  - the popup closes once its field leaves the viewport.
- Before, each popup behaved differently: the select list closed on page scroll, the multi-select followed, and the picker and menus stayed put.

## Apply in your app (the installer does not update this code)
Scripted popups need the helper below. Reference: `followAnchor()` in `src/playground/lib.js`, which uses the existing `anchorPopover()`:

    function followAnchor(pop, anchor, onGone) {
      let queued = false;
      const update = (e) => {
        if (e && e.type === "scroll" && pop.contains(e.target)) return;
        if (queued) return;
        queued = true;
        requestAnimationFrame(() => {
          queued = false;
          if (!pop.isConnected) return;
          const r = anchor.getBoundingClientRect();
          if (r.bottom < 0 || r.top > innerHeight || r.right < 0 || r.left > innerWidth) onGone && onGone();
          else anchorPopover(pop, anchor);
        });
      };
      addEventListener("scroll", update, { capture: true, passive: true });
      addEventListener("resize", update, { passive: true });
      return () => { removeEventListener("scroll", update, { capture: true }); removeEventListener("resize", update); };
    }

- Call it right after a popup is shown and anchored: `const unfollow = followAnchor(popup, field, () => close(false));`. Call `unfollow()` in close.
- In the select fallback (`tm-select.js`), this replaces the v0.1.4 `scrolled` listener: do not close on page scroll, follow instead.
- For native `popover` menus, attach it in the `toggle` event when the menu opens and remove it when it closes. `onGone` calls `pop.hidePopover()`.
