Rules and packaging update. The CSS is unchanged from v0.1.0.

## Changed
- **Errors are toasts.** Record problems (failed check, timeout, stale data) are condition toasts. A failed action is a danger toast that stays until closed, and the same message is not stacked twice. A lost connection is a condition toast that leaves by itself on reconnect. No alert is pushed above the content.
- **No problem markers in records.** The "!" marker beside a record name is gone. Instead, hovering or focusing a toast gives its record's frame the toast's tone at double weight: border color plus a same-width outer outline, so nothing moves. A same-weight recolor is barely visible in Dark and Coffee.
- **The skill zip bundles `references/DESIGN.md` and `references/distribution.md`**, so an install without a repository checkout has the full rules.
- `scripts/release-assets.sh` builds the release zips and `SHA256SUMS`.

## Upgrade
Re-run the installer from the project root. It replaces only the directories it created:

    curl -fsSL https://github.com/hipotures/the-mechanics/releases/latest/download/install.sh | sh
