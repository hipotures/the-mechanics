# Fixture usage and derived data

All demo content comes from [`fixtures/demo-data.json`](../fixtures/demo-data.json) (imported at build time; no network, no random values, no live timestamps). Dates are formatted in UTC with the `en-US` locale. Presentation-only derivations live in [`src/playground/derived.js`](../src/playground/derived.js) and are listed here.

## Analytics
| Derived | Source / rule |
|---|---|
| KPI sparklines | `requests` = API + Worker sum of `charts.requests`; `tokens` = sum of `charts.tokens` series; `cache` = `cache-hit`; `latency` = `ttft` p95; `cost` = `cost-trend`; `errors` = `error-rate` y values; `queue` = `queue` Waiting. `workers` has no sparkline. |
| KPI good/bad direction | requests ↑ good, cache ↑ good, latency/cost/errors/queue ↓ good, tokens neutral. Shown with arrow + sign + screen-reader text, not color alone. |
| “1 offline” badge | `denominator − value` of the workers KPI. |
| Region grouping | 16 charts grouped into *Traffic & throughput*, *Latency & reliability*, *Capacity & cost*. |
| Service filter tags | Mapping of each chart to `serviceOptions` (API / GPU Workers / Queue). |
| Stale panel | `stalePanel` (17 min) applied to the `gpu-memory` chart and the page-level warning. |
| State panels | `errorPanel` shown as panel “External provider sync”; `emptyPanel` shown as panel “Batch export volume” and in every time-series panel when 7d/30d is selected (fixture only contains 24h). |
| Scatter highlight | Points with error rate ≥ 1 % use the danger series and square markers (presentation rule, not a fixture threshold). |

## Workspace
| Derived | Source / rule |
|---|---|
| Tabs | `preview.tabs`; annotations with type `place`/`facility` listed under *Terms*, `role` under *Observations*. |
| Long-term stress row | `states.longTerm` added to the Terms table with a synthetic Polish note. |
| Other units | Only `preview.unitId` has blocks; other units show an explicit empty state. |
| Load next | `navigation.hasNext`/`pageSize` → loading skeleton then an “end of demo fixture” notice. |

## Data management
| Derived | Source / rule |
|---|---|
| Initial selection | `selectionSample.selectedIds` (gives the indeterminate header on page 1). |
| Editor draft | New-account draft uses `validationSamples.invalidEmail`, `invalidNumber`, `componentStates.formExamples.select/textarea` so validation errors are visible on load. |

| Empty query | `emptyQuery` used by the smoke test. |

## Catalog
| Derived | Source / rule |
|---|---|
| Product images | Original SVGs generated by `scripts/gen-product-images.mjs` for every `imageKey` → `public/products/`. |
| Missing image | `edgeCases.missingImageKey` is used as the second (“Detail”) view in every product drawer; no file exists, so the failure state renders. |
| Price filter max | Highest price rounded up to 10. |
| Gallery “old price” | $95.00 is a gallery-only specimen (fixture has no sale prices). |

## Content site / gallery
Website copy is used verbatim. The “About this project” paragraph, figure captions, CTA copy and token table are original synthetic text. The gallery reuses fixture strings (`stressText`, `statusValues`, `formExamples`, records, products).
