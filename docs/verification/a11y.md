# Accessibility scan (axe-core)

`corepack pnpm build && corepack pnpm a11y` runs axe-core 4.14.0 (rules tagged
WCAG 2.0/2.1/2.2 A and AA, plus best-practice) on all six pages × three
themes × desktop (1440×900) and mobile (390×844), with reduced motion on.
The JSON report goes to `tmp/a11y/axe.json` and the run fails on any
violation that is not a documented exemption.

Automated rules cover only part of WCAG. Keyboard paths, focus return and
visual states are covered by `pnpm smoke` and by screenshot review.

## Result (2026-11-18)

0 violations in 36 runs, after the fixes below. The first run found 6 rules.

| Rule | Where | Fix |
|---|---|---|
| color-contrast | Dark/Coffee: muted text, counts, negative amounts and danger buttons on the selection fill (3.2–3.6:1) | `--tm-select-bg` darkened (Dark `#4a5c3a` → `#3b492e`, Coffee `#74492a` → `#5f3c23`), `--tm-danger` lifted slightly (Dark `#f39b8c`, Coffee `#f39b84`). Text-2/3, all status hues and links now pass 4.5:1 on the selection fill; `check:contrast` checks these pairs. |
| color-contrast | daisyUI bridge: inactive tab label at 50% text (~3:1) | Adapter sets inactive `.d-tab` to `--tm-text-2`. |
| aria-allowed-attr | Gallery: static command palette and multi-select specimens used `aria-selected` without roles | Static specimens use the same `listbox` / `option` structure as the live components. |
| aria-allowed-role | Sheet used `<aside role="dialog">` / `role="group"` | Sheet is a `<div>`; recipe updated. |
| link-name | Mobile: brand link had no name once its text was hidden | Text is visually hidden instead of `display: none`. |
| empty-table-header, scrollable-region-focusable | Gallery matrix corner cell; code block on Content Site; matrix wrapper on mobile | Hidden header text; `tabindex="0"` on the scrollable `<pre>` and on the labelled matrix region. |
| aria-prohibited-attr (needs review) | Product rating and heat ramp had `aria-label` on elements without a role | `role="img"`. |

## Exemptions

WCAG 1.4.3 does not apply to inactive UI components. Disabled rows
(`.is-disabled`, for example excluded chapters in Workspace) and the
`tm-badge--disabled` specimen use `--tm-text-disabled` on purpose. The script
lists them in the report but does not fail on them.
